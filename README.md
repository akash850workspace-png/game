# 🏰 Settlement Simulation - Emergent World Game

> **一个真正的涌现式世界模拟游戏** - 500+可重用构建块，数千个相互作用的NPC，持久的世界状态，真正的知识，真正的记忆，真正的关系，真正的经济，真正的生态，真正的家庭，真正的派系，真正的后果，真正的因果关系，玩家代理，大规模历史 = **涌现世界**

---

## 🎯 项目目标

构建一个**真正的涌现式世界模拟**，其中：

- ✅ 故事从模拟历史中**涌现**，而不是被编写
- ✅ 每个事件都有**真实的因果关系**
- ✅ NPC行为从**内部状态**涌现
- ✅ 玩家可以**永久改变**家庭的未来
- ✅ 小事件可以**成长为巨大后果**
- ✅ 模拟可以**大规模运行**而不会崩溃

---

## 🏗️ 架构

```
世界状态
  ↓
感知
  ↓
知识
  ↓
压力（受记忆、关系、目标影响）
  ↓
可用行动
  ↓
行动分数（带分解）
  ↓
选择
  ↓
结果
  ↓
状态变化
  ↓
记忆/知识变化
  ↓
关系/目标变化
  ↓
新压力
  ↓
新决策
  ↓
新事件
  ↓
后果
```

## ✨ 核心特性

### 🧠 真正的因果关系
- 每个事件都有基于实际状态变化的父节点
- 因果追踪器追踪所有状态变化
- 可以回答"为什么会发生这个？"
- 因果边经过验证

### 💭 记忆系统
- 记忆影响未来决策
- 盗窃记忆增加警惕和复仇
- 暴力记忆增加恐惧
- 积极社交记忆减少孤独
- 记忆有显著性和置信度

### 🤝 关系动态
- 关系影响决策
- 偷窃优先选择低信任目标
- 战斗优先选择低好感目标
- 关系因事件而变化
- 关系有历史

### 🎯 目标驱动行为
- NPC追求目标
- 目标影响压力
- 复仇目标增加复仇压力
- 还债目标增加财富需求
- 目标从未完成的事件中涌现

### 📚 知识系统
- NPC只知道他们应该知道的
- 知识通过社交网络传播
- 传闻比目击的置信度低
- 知识影响决策

### 📊 决策解释
- 每个决策都有分数分解
- 显示压力、特质、记忆、关系、目标的贡献
- 可以解释为什么NPC做出特定选择

### ⚡ 性能优化
- 索引系统实现快速查找
- NPC按地区、派系、职业、家庭索引
- 事件按类型、NPC、位置、时间索引
- 支持1000+ NPC

## 🔬 因果链示例

```
E100: A从B偷窃
  ↓ (B.coin: 100 → 80)
  ↓ (B.trust[A]: 0.5 → 0.0)
  ↓ (B获得记忆: valence=-0.7, salience=0.8)
  
E115: B决定避开A
  ↓ (父节点: E100)
  ↓ (压力: safety=0.6, vengeance=0.4)
  ↓ (记忆影响: 盗窃记忆增加safety)
  ↓ (关系影响: 低信任减少socialize效用)
  
E130: B告诉C关于盗窃
  ↓ (知识传播)
  ↓ (C.heardEvents.add(E100))
  ↓ (C.beliefs: "A从B偷窃" confidence=0.7)
  
E145: C决定不与A交易
  ↓ (父节点: E100 通过知识)
  ↓ (知识影响: C知道A不诚实)
```

## 📝 开发原则

1. **模拟第一** - 故事从模拟中涌现
2. **因果关系第二** - 每个事件都有真实原因
3. **故事第三** - 故事从历史中提取
4. **任务第四** - 任务从未解决的情况中涌现
5. **呈现最后** - UI展示模拟历史

**永远不要颠倒这个顺序。**
